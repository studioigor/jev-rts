# JEV RTS

<img src="https://raw.githubusercontent.com/studioigor/jev-rts-assets/main/Documentation~/preview.jpg" alt="Мир JEV RTS — Сумеречная переправа" width="480">

**RTS-эксперимент для видео на YouTube-канале studioigor: что получится, если доверить искусственному интеллекту решения целой армии?**

Две фракции начинают с ратуши и одного рабочего. Вокруг — лес, золотые рудники, река с переправами и территория, скрытая туманом войны. Рабочим предстоит добывать ресурсы и строить базу, мечникам — встречать противника в ближнем бою, лучникам — поддерживать их на расстоянии. Побеждает сторона, уничтожившая вражескую ратушу.

За привычной формой стратегии «люди против нежити» находится главный эксперимент: решения юнитов, выбор маршрутов и стратегия противника поступают от **JEV API**. Unity исполняет эти решения в игровом мире и следит за его правилами — экономикой, движением, столкновениями, боем и видимостью. Если сервис недоступен, игра сообщает об этом: скрытого локального ИИ, который продолжит принимать решения вместо JEV, здесь нет.

Это исходники проекта из видео: можно изучить, как наблюдение за миром превращается в запрос, как ответ становится приказом и что происходит, когда множество таких приказов встречаются на одной карте. Проект оставлен открытым для собственных экспериментов с правилами, фракциями, интерфейсом и поведением юнитов.

## Что внутри

- Экономика с деревом и золотом, строительство, производство юнитов и очередь найма.
- Рабочие, мечники и лучники у людей и нежити; управление отдельными юнитами и группами.
- JEV на уровне отдельных юнитов и командира противника, проверка ответов и ограничения сетевых запросов.
- Туман войны, камера RTS, интерфейс матча и процедурные звуковые эффекты.
- Собранное в Unity окружение: лес, некрополь, вода, огонь, ветер и погода — через отдельный пакет графики.
- Локальные тесты и отдельная сцена для исследования навигации через узкий проход.

Проект для YouTube-канала [**studioigor**](https://www.youtube.com/@studioigor).

## Два репозитория

- **JEV RTS** — этот Unity-проект: игровая логика, интерфейс, игровые сцены, конфигурация и тесты.
- [**JEV RTS Assets**](https://github.com/studioigor/jev-rts-assets) — отдельный UPM-пакет `com.studioigor.jev-rts-assets`: вся графика, модели, анимации, визуальные префабы, окружение и редактируемые исходники. Игра подключает его напрямую, поэтому графика здесь не дублируется.

## Запуск

1. Установите **Unity 6000.6.2f1** через Unity Hub. Проект использует **URP 17.6.0** и Input System **1.20.0**; зависимости зафиксированы в `Packages`.
2. Клонируйте оба репозитория рядом, сохранив имя папки пакета:

   ```sh
   git clone https://github.com/studioigor/jev-rts.git "Jev RTS"
   git clone https://github.com/studioigor/jev-rts-assets.git "JEV RTS Assets"
   ```

   ```text
   workspace/
   ├── Jev RTS/          ← этот репозиторий, открывается в Unity Hub
   └── JEV RTS Assets/   ← репозиторий ассетов, package.json в корне
   ```

   `Packages/manifest.json` уже содержит зависимость `file:../../JEV RTS Assets`. Путь считается от папки `Packages`. Для другого расположения выберите **Window → Package Manager → + → Install package from disk** и укажите `package.json` пакета.
3. В папке игры создайте `LocalSettings/jev.env` по образцу `jev.env.example`:

   ```dotenv
   JEV_API_KEY=your_api_key_here
   ```

   Также поддерживается переменная окружения `JEV_API_KEY`, унаследованная процессом Unity. Ключ не записывается в сцену или ассеты. В самостоятельной сборке файл читается из `Application.persistentDataPath/LocalSettings/jev.env`.
4. Откройте проект через Unity Hub и дождитесь импорта пакетов.
5. Откройте `Assets/_Jev/Scenes/Gameplay/JevRtsMatch.unity`, нажмите **Play**, выберите фракцию и начните матч.

Endpoint и ограничения запросов задаются в `Assets/_Jev/Settings/Gameplay/MatchSettings.asset`. Исходные значения: `https://api.typesafe.ai/v1/systemone`, модель `jev-1.13.0`. Требуется собственный доступ к JEV; запросы используют ваш ключ и лимиты аккаунта. Оценка стоимости в интерфейсе вычисляется по редактируемым тарифам конфигурации.

Без ключа доступны открытие сцен, редактирование мира и локальные тесты; полноценный матч требует ответов JEV. Локальные конфигурации и журналы в `LocalSettings` исключены из Git.

## Управление

| Действие | Управление |
| --- | --- |
| Выбор юнита / группы | ЛКМ / рамка, Shift — добавить |
| Движение, добыча, строительство, атака | ПКМ по земле или цели |
| Перемещение камеры | WASD, стрелки, край экрана |
| Приближение / поворот | Колесо / Q, E или средняя кнопка мыши |
| Удерживать позицию | H |
| Выбрать всю армию | Tab |
| Перейти к выбранному | Space |
| Пауза / отмена размещения | Esc |

## Настройка и сборка

Игровые настройки находятся в `Assets/_Jev/Settings/Gameplay`, игровые префабы — в `Assets/_Jev/Prefabs/Gameplay`, код — в `Assets/_Jev/Scripts/Gameplay`. Авторские точки стартовых ратуш редактируются компонентом `StartingTownHallAnchor` в сцене. Визуальные материалы, модели и части уровня находятся в **Packages → JEV RTS Assets → Runtime**.

Для сборки откройте **File → Build Profiles**, выберите установленную платформу и оставьте `JevRtsMatch` первой включённой сценой. Ключ настраивается на машине, запускающей сборку, отдельно от игровых файлов.

## Проверки

Откройте **Window → General → Test Runner → EditMode → Run All**. Локальные тесты проверяют симуляцию, обработку команд, протокол JEV и интерфейс; реальный API для них не требуется.

При подготовке репозитория на Unity 6000.6.2f1 прошли **234 из 234** EditMode-тестов; три сцены проверены на потерянные скрипты и ошибки материалов.

Сцена `Assets/_Jev/Scenes/Diagnostics/JevRtsChokepoint.unity` проверяет навигацию через узкий проход. При запуске Play она обращается к настоящему JEV API. Результат локальных тестов не является проверкой доступности сервиса или полной партии против ИИ.

В репозитории нет ключей, пользовательских настроек Unity, кэша `Library`, сборок и истории разработки. Уведомления о происхождении графики и сторонних лицензиях находятся в репозитории **JEV RTS Assets**.
